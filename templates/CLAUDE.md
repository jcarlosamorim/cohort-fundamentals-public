## Comandos Que Ja Aprendi

### Terminal Basico
| Comando | O que faz | Quando usar |
|---------|-----------|-------------|
| `pwd` | Mostra onde estou | Quando me perder nas pastas |
| `ls` ou `ls -la` | Lista arquivos da pasta | Para ver o que tem aqui |
| `cd pasta` | Entra numa pasta | Para navegar |
| `cd ..` | Volta uma pasta | Para subir um nivel |
| `mkdir nome` | Cria uma pasta | Para organizar meu projeto |

### Dentro do Claude Code
| Comando | O que faz |
|---------|-----------|
| `/help` | Lista todos os comandos disponiveis |
| `/init` | Cria o CLAUDE.md automaticamente |
| `/status` | Mostra versao, modelo e conta conectada |
| `/clear` | Limpa a conversa e comeca fresco |
| `/exit` | Sai do Claude Code |
