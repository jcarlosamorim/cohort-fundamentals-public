Stack 0 — Pre-Requisito

Instalando o Claude Code

1 comando. Zero dependencias. Funciona em Mac, Windows e Linux. Sem Node.js. Sem downloads manuais.

Novidade 2026: Claude Code agora tem instalador nativo. Nao precisa de Node.js, npm, nem nenhuma dependencia. O comando abaixo baixa e instala tudo automaticamente.
Instalar Claude Code
1. $ curl -fsSL https://claude.ai/install.sh | bash Instalar (tambem funciona em Linux/WSL)
1. > curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd Instalar
1. PS> irm https://claude.ai/install.ps1 | iex Instalar
Claude Code instalado com sucesso
2. $ claude doctor Verificar se instalou certo
Mostra versao, tipo de instalacao e problemas potenciais
3. $ claude Abrir pela primeira vez
Abre o browser para login. Use sua conta Claude Pro, Max ou Teams.

Alternativas de Instalacao

Stack 2

Interface do Claude Code

Claude Code e uma ferramenta de terminal. Nao tem janelas, menus visuais nem sidebar. E voce conversando com uma IA direto na linha de comando.

O Que Voce Ve

As areas do terminal

Pra Que Serve

A funcao de cada area

Area 1 Prompt (onde voce digita)
Linha de Comando

O cursor piscando no final da tela. Voce digita em linguagem natural — como se estivesse mandando mensagem.

Como Usar

Descreva o que quer. Claude entende contexto. "Crie um arquivo README" funciona. Nao precisa saber programar.

Area 2 Resposta do Claude (fluxo de texto)
Conversa no Terminal

Claude responde direto no terminal. Texto, codigo, explicacoes — tudo rola pra cima conforme a conversa avanca.

O Que Aparece

Claude mostra o que vai fazer, pede permissao, e executa. Voce ve cada arquivo lido, editado ou criado em tempo real.

Area 3 Permissoes (aceitar ou negar)
Controle de Permissoes

Quando Claude quer executar um comando ou editar um arquivo, ele para e pergunta. Voce aprova com y ou nega com n.

Voce e o Piloto

Claude nao executa nada sem sua aprovacao. Cada acao — ler arquivo, editar codigo, rodar comando — ele para e pergunta. Voce decide: y (sim) ou n (nao).

Quer modo autonomo (YOLO)? Abra o Claude assim:

$ claude --dangerously-skip-permissions

Nesse modo, Claude executa tudo sozinho sem perguntar. Use quando confiar no que pediu.

Realidade:

Claude Code nao tem janelas bonitas. E um terminal. Texto puro. Mas e justamente por isso que e poderoso — ele le, edita e cria arquivos direto no seu sistema, sem intermediarios. Voce ta aprendendo a viver dentro do terminal.

Comandos Essenciais (Slash Commands)

Dentro do Claude Code, digite / para ver o menu. Esses 6 voce usa no dia 1:

Claude Code — Slash Commands
1. > /help Mostra todos os comandos disponiveis
2. > /init Cria o CLAUDE.md no projeto (a fita de Lucy)
3. > /status Versao, modelo, conta conectada
4. > /clear Limpa a conversa (fresh start)
5. > /exit Sai do Claude Code
6. > ! ls -la Roda comando bash direto (prefixo !)
