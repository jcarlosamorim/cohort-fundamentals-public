Instale o AIOS no Seu Terminal

Chega de teoria. Agora voce vai instalar o framework no seu computador. Siga cada passo na sequencia exata — sem pular, sem improvisar.

Importante

Feche todos os terminais abertos antes de comecar. Um ambiente limpo evita conflitos de sessao.

1
Feche todos os terminais

Terminal, iTerm, PowerShell, CMD — tudo. Estamos comecando do zero.

Mac: Cmd + Q
Win: Alt + F4
2
Abra um novo terminal

Um terminal fresco, sem historico de sessao anterior.

Mac: Spotlight → Terminal
Win: Win + R → cmd
3
Crie a pasta de projetos

Uma pasta dedicada para todos os seus projetos com IA. Se ja existe, pule este passo.

Terminal
$ mkdir code
4
Entre na pasta

Navegue para dentro da pasta que acabou de criar.

Terminal
$ cd code
5
Instale o AIOS

Este unico comando baixa o framework completo, cria a estrutura de pastas e configura tudo. Cole, aperte Enter e aguarde.

Terminal — Comando Principal
$ npx aios-core@latest install
Need to install the following packages:
aios-core@4.2.12
Ok to proceed? (y)
github.com/allfluence/aios-core
