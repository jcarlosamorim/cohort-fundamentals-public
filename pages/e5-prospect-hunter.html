As Ferramentas

4 Pecas Que Fazem a Maquina Funcionar

Cada ferramenta tem um papel. Juntas, elas formam um sistema completo de prospeccao.

Apify — O Coletor
API + Token
Scraping automatizado. Conecta no Instagram, LinkedIn, Google Maps. Extrai dados de perfis em massa.
Actor: scraper especializado que voce configura com filtros
JSON — Armazenamento Local
Local + Zero Config
Armazenamento local em JSON. Zero configuracao, zero custo. Arquivos .json guardam todos os leads. Perfeito para MVP.
Stack: arquivos .json, sem servidor, leitura direta
Gemini API — O Escritor
Gratuito · 15 RPM
Gera mensagens de prospeccao hiper-personalizadas. Le a bio e ultimos posts do prospect e escreve uma mensagem unica. O melhor: e 100% gratuito.
Modelo: Gemini 2.0 Flash — rapido, gratuito, sem cartao de credito
Vercel — A Vitrine
Deploy
Deploy automatico. Dashboard web para visualizar leads, filtrar, exportar. Acesso de qualquer lugar.
Infra: Serverless functions + CDN global

O Diferencial

Exemplo de Mensagem Personalizada

Veja como a Gemini API transforma dados brutos em uma mensagem que parece escrita a mao.

Input — Dados do Apify
nome: "Marina Costa"
cargo: "Head de Growth @ TechCorp"
bio: "Apaixonada por dados e growth hacking"
ultimo_post: "Como reduzimos churn em 40% com onboarding personalizado"
Output — Mensagem da Gemini API
Marina, vi seu post sobre reducao de churn com onboarding personalizado — 40% e impressionante. Estou trabalhando em algo que complementa exatamente isso: [sua proposta de valor]. Faz sentido uma conversa de 15min?
Gemini Flash

Por que isso funciona

Essa mensagem nao e generica. Ela referencia o post real da Marina. E isso que faz a taxa de resposta subir de 2% para 15%+. O prospect sente que voce pesquisou sobre ele — porque a IA pesquisou.
