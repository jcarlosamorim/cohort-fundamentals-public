Bloco 2 — Teoria

Anatomia de uma Task AIOS

Tudo que um agente faz de util esta dentro de uma task. Tasks sao os blocos de construcao do AIOS — instrucoes executaveis que qualquer agente pode consumir.

Onde moram as tasks?
.aios-core/
development/
tasks/ ← TODAS as tasks moram aqui
create-doc.md
execute-epic-plan.md
qa-gate.md
create-wave-map.md ← vamos criar essa!

Estrutura de uma Task (Formato AIOX V1.0)

1
Task Definition

Nome, responsavel, entrada (o que recebe), saida (o que produz). Formato YAML.

2
Pre/Post-Conditions

O que precisa existir ANTES, e o que deve ser verdade DEPOIS. Sao os gates de qualidade.

3
Acceptance Criteria

Checklist objetiva: a task so esta DONE quando todos esses criterios forem verdade.

4
Execution Body

O algoritmo passo-a-passo. O que o agente realmente FAZ quando executa a task.

Como um agente "sabe" que a task existe?

Cada agente tem uma secao dependencies.tasks no seu arquivo de definicao. Quando voce adiciona o nome de uma task nessa lista, o agente passa a ter acesso a ela. Sem esse registro, a task existe mas o agente nao sabe.

Bloco 5 — Entendendo a Integracao

Como a task se conecta ao agente

Criar o arquivo da task e so metade. Para o agente "saber" que ela existe, precisamos de 3 conexoes no arquivo do agente.

A
Comando na secao commands:

Adiciona *wave-map na lista de comandos do agente. E o que o usuario digita.

B
Dependencia na secao dependencies.tasks:

Registra o arquivo da task na lista de dependencias. Sem isso, o agente nao carrega o conteudo.

C
Entrada no Quick Commands

Documenta o comando na secao de referencia rapida. Aparece quando o usuario digita *help.

Resultado

Depois da integracao, voce ativa o PM com /AIOS:agents:pm e digita *wave-map docs/stories/epics/cardapio-digital. O agente vai ler as stories, montar as waves e gerar o YAML com prompts prontos pra copiar.

O Poder do Wave Development

Com wave-map, voce nao executa 3 stories em sequencia (3x o tempo). Voce executa 2 em paralelo + 1 depois. Em vez de 3 horas, termina em 2. Com epics maiores (10+ stories), a diferenca e brutal — o paralelismo pode cortar o tempo pela metade.
