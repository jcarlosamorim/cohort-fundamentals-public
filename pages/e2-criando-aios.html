Instalando o Squad Creator

Agora que voce conhece o time, vamos usar o Orion (aios-master) para instalar o primeiro expansion pack: Squad Creator PRO.

1
Baixe o Squad Creator PRO
Va em Downloads e baixe o arquivo squad-creator
squad-creator
Expansion Pack — disponivel na area de Downloads do cohort
2
Ative o Orion (aios-master)
No terminal, digite /mast e o autocomplete mostra o caminho completo
claude-code
$ /mast ← comece a digitar
/AIOS:agents:aios-master
← clique Enter
3
Cole o comando de instalacao
Copie e cole no terminal onde o Orion esta ativo
aios-master (Orion)
$ Instale o squad-creator que esta em downloads/squad creator premium, adicionando inclusive os slashs "/" para ativa-lo.
! Use Claude Opus 4.6 para instalar

O Orion vai copiar os arquivos, registrar os agentes e criar os comandos /SquadCreator:* automaticamente. Acompanhe o progresso no terminal.

Como Instalar um Squad Manualmente

Se preferir instalar um squad sem o Orion, basta seguir este processo em 3 passos.

1
Colocar o squad na pasta squads/
O squad precisa ter esta estrutura minima
Estrutura
squads/{nome-do-squad}/
├── config.yaml OBRIGATORIO — define nome e slashPrefix
├── agents/ Agentes (.md)
├── agent-chief.md
└── outro-agent.md
├── tasks/ Tasks (.md)
└── minha-task.md
└── workflows/ Workflows (.yaml) — opcional
2
Rodar o sync para gerar os slash commands
Este comando cria os /NomeDoSquad:* no Claude Code
Terminal
$ python squads/squad-creator-pro/scripts/sync-ide-command.py squad {nome-do-squad}
3
Testar os comandos
Abra o Claude Code e digite /NomeDoSquad: para ver os comandos gerados
claude-code
$ /NomeDoSquad: ← autocomplete mostra os comandos
agents:agent-chief
tasks:minha-task

Este metodo e util quando voce recebe um squad como .zip ou cria um do zero. O Orion (metodo automatico) faz exatamente estes passos por voce.

Descobrindo a Zona de Genialidade

Antes de construir qualquer coisa, voce precisa saber onde voce brilha. A Zona de Genialidade e o conceito criado por Gay Hendricks que identifica a interseccao entre o que voce ama fazer, o que faz com facilidade natural e o que gera impacto real.

As 4 Zonas de Gay Hendricks
Incompetencia

Coisas que outros fazem melhor. Delegue sem culpa.

Competencia

Voce faz bem, mas nao melhor que a media. Nao diferencia.

Excelencia

A armadilha dourada. Voce e muito bom, mas nao e o seu genio.

Genialidade

Onde voce perde a nocao do tempo. Seu talento unico. E aqui que queremos chegar.

Por que isso importa? Quando voce constroi um negocio a partir da sua zona de genialidade, o trabalho flui naturalmente. Voce nao precisa de motivacao — precisa apenas de clareza sobre onde o seu genio mora.

1
Baixe o Zona de Genialidade
