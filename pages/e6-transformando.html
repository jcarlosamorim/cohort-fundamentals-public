Bloco 1

Do Vibecoding ao GitHub

O primeiro passo e tirar o projeto da plataforma de vibecoding e colocar no GitHub. Cada plataforma tem um jeito diferente de exportar.

Bolt.new
1. Abra seu projeto no Bolt
2. Clique em Deploy
3. Selecione GitHub
4. Escolha o repositorio ou crie um novo
v0.dev
1. Abra seu projeto no v0
2. Clique nos 3 pontos
3. Selecione Deploy → GitHub
4. Conecte sua conta e exporte
Lovable
1. Abra seu projeto no Lovable
2. Va em Settings
3. Clique em Connect GitHub
4. Sincronize o repositorio

Bloco 3

Configurando Supabase e Vercel

Credenciais sao as chaves que conectam seu projeto aos servicos externos. Vamos configurar tudo de forma segura.

Credenciais Supabase
1
Project URL
Settings → Data API → copie a Project URL
2
Anon Key
Settings → API Keys → copie a Legacy Anon Key
3
Service Role Key
Settings → API Keys → copie a Legacy Service Role Key
Prompt para colar no Claude Code
Crie um arquivo .env na raiz do projeto
com estas credenciais do Supabase:
 
SUPABASE_URL=
SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
 
Verifique se o .gitignore ja tem .env
listado. Se nao tiver, adicione.
Token Vercel
1
Abra a pagina de tokens
Acesse vercel.com/account/tokens
2
Crie o token
Clique em Create Token. Name: claude-code. Scope: Full Account. Expiration: 90 dias ou No Expiration.
3
Copie imediatamente
O token so aparece uma vez. Copie antes de fechar a pagina!
Prompt para colar no Claude Code
Adicione no .env esta credencial da Vercel:
 
VERCEL_TOKEN=
 
Verifique se o .gitignore ja tem .env listado.
NUNCA suba credenciais pro GitHub
O arquivo .env contem suas senhas. Ele DEVE estar no .gitignore para nao ser enviado ao GitHub. Se subir por acidente, suas chaves ficam publicas e qualquer pessoa pode usar.
Bloco 4

Brownfield Discovery

Brownfield e quando voce pega um projeto que ja existe e precisa entender tudo antes de melhorar. O discovery mapeia a estrutura inteira automaticamente.

Arquitetura
Mapeia todas as pastas, arquivos e como eles se conectam.
Tech Stack
Identifica todas as tecnologias, frameworks e dependencias usadas.
Debitos Tecnicos
Encontra problemas, codigo duplicado e melhorias necessarias.
Relatorio
Gera um documento completo com tudo que foi encontrado e proximos passos.
Prompt para colar no Claude Code
COPIE
Execute o brownfield discovery neste projeto
para mapear toda a estrutura existente.
Analise arquitetura, tech stack, dependencias
e gere um relatorio completo.
Greenfield
Projeto novo do zero. Voce decide tudo. Nao tem codigo legado. E como construir numa terra vazia.
Brownfield
Projeto que ja existe. Voce precisa entender antes de mudar. Discovery mapeia o terreno. E como reformar uma casa ja construida.
