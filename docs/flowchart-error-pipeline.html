Simulacao completa: do erro ate o diagnostico no WhatsApp

Como o tool_use funciona aqui?

O tool_use NAO executa codigo nem aplica fixes. Ele e um mecanismo da API Claude que forca o modelo a retornar JSON estruturado em vez de texto livre. Pense nele como um "formulario" que o Opus preenche.

Sem tool_use (texto livre)
"O erro parece ser um TypeError porque
a funcao renderTalents esta tentando
chamar .map() em undefined. Isso
provavelmente acontece quando..."

// Texto livre, dificil de parsear
// Formato imprevisivel
// Nao da pra salvar no banco
// Nao da pra formatar no WhatsApp
Com tool_use (JSON estruturado)
{
  "root_cause": "renderTalents chama...",
  "severity_assessment": "high",
  "category": "runtime",
  "file_likely": "js/psicometria-upload.js",
  "line_likely": "142",
  "suggested_fix": "if (!Array.isArray...",
  "auto_fixable": true,
  "confidence": 0.88
}

// Previsivel, parseavel, salvavel

Simulacao: Erro real no Psicometria Upload

Trigger: Usuario faz upload de documento

💥
1. Erro ocorre no browser do usuario T+0ms
O usuario fez upload de um PDF. A API retornou o resultado, mas o campo talents veio como undefined. A funcao renderTalents() tentou chamar .map() em undefined.
// js/psicometria-upload.js:142
function renderTalents(talents) {
  return talents.map(t => ...); // 💥 TypeError: Cannot read properties of undefined (reading 'map')
}
📡
2. ErrorLogger.js captura automaticamente T+1ms Fase 1
window.onerror intercepta o erro. ErrorLogger monta o payload e envia para /api/error-log.
// ErrorLogger.capture() automatico
POST /api/error-log
{
  "severity": "error",
  "source": "frontend",
  "message": "Cannot read properties of undefined (reading 'map')",
  "stack": "at renderTalents (js/psicometria-upload.js:142:35)...",
  "url": "https://fundamentals-theta.vercel.app/home#/psicometria"
}
⚡
3. /api/error-log processa T+200ms
Gera UUID, salva no Supabase com fix_status: 'new', chama Haiku para explicacao rapida.
// Supabase INSERT
{
  "id": "4eb7d635-8cba-46e5-...",

  "severity": "error",
  ...
}
💾
4. Supabase: error_logs INSERT T+400ms
Linha salva na tabela error_logs com todos os campos + fix_status = 'new'

10. Opus 4.6 analisa com tool_use T+4s → T+30s CORE
AQUI esta o tool_use em acao. O endpoint envia o erro para Opus 4.6 com tool_choice: { type: 'tool', name: 'diagnose_and_fix' }. Isso FORCA o Opus a preencher um JSON com campos obrigatorios. Opus NAO executa nada — ele ANALISA e PREENCHE o formulario.
// Request para Anthropic API
{
  "model": "claude-opus-4-6",
  "max_tokens": 4096,
  "system": "You are an expert debugger for Cohort Fundamentals...",
  "messages": [{ "role": "user", "content": "ERRO: TypeError... at renderTalents..." }],
  "tools": [{
    "name": "diagnose_and_fix",
    "input_schema": {
      "required": ["root_cause", "severity_assessment", "suggested_fix", ...]
    }
  }],
  "tool_choice": { "type": "tool", "name": "diagnose_and_fix" }
  // ^ FORCA Opus a usar esta tool — nao pode responder texto livre
}

13. Humano decide Acao humana
Voce recebe as 2 mensagens no WhatsApp. Com o diagnostico completo, voce pode:
  • Aplicar o fix manualmente — abrir o arquivo, fazer a mudanca sugerida

Safety Net: Cron Diario
